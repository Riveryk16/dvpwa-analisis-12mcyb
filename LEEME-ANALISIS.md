# Aviso: esta aplicación es vulnerable a propósito. NO la despliegues.

Esta copia existe para un trabajo académico: la **Actividad 2 de Código Seguro y QA (12MCYB)**
del Máster en Ciberseguridad de la VIU, curso 2026. El ejercicio consiste en pasarle herramientas
de análisis estático a una aplicación y explicar lo que reportan.

- **Original:** [anxolerd/dvpwa](https://github.com/anxolerd/dvpwa) — *Damn Vulnerable Python Web
  Application*, de Oleksandr Kovalchuk, bajo la licencia que acompaña al repositorio (`LICENSE`),
  que se conserva sin cambios.
- **Instantánea analizada:** commit `a1d8f89` del original (04/11/2022).
- **Qué se cambió aquí:** nada del código. Solo se añadió este aviso.

La aplicación contiene fallos de seguridad **plantados deliberadamente** por su autor con fines
didácticos, y sus dependencias están congeladas en versiones de 2018 con vulnerabilidades
conocidas. No la ejecutes ni la expongas en una red: no es código de ejemplo que imitar, es el
caso de estudio.

El análisis se hizo **sin ejecutar la aplicación**, leyendo únicamente su código y sus ficheros
de dependencias.
